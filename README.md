# dMAT General Academic Practice Website

The site is a dependency-free static web app. It contains:

- a medium/high full simulator with 20 Figure Sequences, 20 Mathematical Equation systems and 20 Latin Squares
- 70 General Academic application/evaluation questions across 14 original source tasks
- seven unique 39-minute daily sets; every set covers all four sections with 28 medium/high questions
- fixed-order real-test simulation with instruction screens, 25-minute core subtests, a timed 30-minute break and a 90-minute General Academic module
- separate focused section-practice mode
- automatic submission at time expiry, locked inter-section progression and hidden difficulty labels in simulation mode
- question navigation, flags and per-question/section timing capture
- post-test diagnostics for raw accuracy, completion, pacing, difficulty level, General Academic knowledge area and targeted next-step recommendations
- complete worked review after the simulation ends
- a dated Autumn 2027 application timeline and country playbooks for Germany, the Netherlands, Ireland and Scotland

## Run locally

From the project directory:

```bash
python3 -m http.server 8765
```

Then open <http://localhost:8765/>.

The material is original and unofficial. It uses the official preparation examples only as a reference for mechanics and task style; no protected questions are copied. Live dMAT questions and exact statistical calibration are not public. Reported results are diagnostic raw scores, not official scores, percentiles or admission predictions.
